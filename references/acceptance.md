## 3. 价值验收：改变了什么决策、作用多大、适用边界

### 3.1 改变了什么决策

冻结基线 B 的规则是「看到负净基差/便宜券就按 1:1 面值建对冲」，
不检查融资成本、不检查 CTD 切换缓冲、不调整对冲比率。
研究方案 C 把决策改为**三道门槛 + 一个比率**：

1. 全成本覆盖：期初 `IRR − r > 49.778bp`（把融资、摩擦、交割费、CTD 缓冲全部计入）；
2. CTD 切换缓冲：期初前二名 IRR 安全垫 > 5bp；
3. 按 DV01 比率而非 1:1 对冲；
4. 门槛不满足则**空仓**并记录 `skip_reason`，而不是按账面偏差建仓。

在基准点，这一改动把「建仓」直接改成「不执行」；在 399 情景中把 273 个
（68.42%）原先会建仓的决策改成不执行。

> **v2 的口径强化**：三道门槛与持仓标的现在**只用结算日可观测信息**判定，
> 四者同源。v1 曾出现「闸门按期初曲线判定、持仓却取冲击后 CTD」的事后选券，
> 且该缺陷同时污染 A / B / C 三条策略。v2 修正后，
> **闸门通过 ⟺ 持仓券的期初 IRR 确实覆盖成本**，不再出现「按一套信息决策、
> 按另一套信息持仓」的错配。

### 3.2 作用多大

> 以下数值全部为 **v2 口径**（`run_id = v2-base-20261119`），取自该 run 的
> `strategy_comparison.csv` 与 `backtest_metrics.json`，零手工转录。

- 被 C 跳过的 **273** 个情景里，B 的条件 P&L 均值 **−0.126895**、
  合计 **−34.642463**、胜率仅 **27.47%**；C 把这些情景的 P&L 改为 0。
  这就是 C 相对 B 的**全部**价值来源（见 §2 的归因拆解）。
- 在 C 仍执行的 126 个情景里，C 与 B 的均值**相同**（均 +0.061418），
  但标准差从 0.168308 收窄到 **0.033854**——DV01 对冲把单档幅度压平，
  逐档最大差异 0.271892 元/百元，60/126 档 C 优于 B。
- 情景序列累积最大回撤：B **−43.555110** → C **0.0**（C 只在执行情景有非零 P&L，
  且执行情景全部为正）。
- 参数网格留出（奇偶切分）C 均值 0.019495 → 0.019294，偏移 0.000201，
  说明结论不依赖网格某一半的偶然性（但**不等价于时间序列样本外**）。
- 微扰检验：10 项扰动（成本 ±10%、r ±2bp、缓冲 ±2bp、期货价 ±0.01 等）下
  CTD 与可执行判定均不翻转；CF 敏感性单独标注并给出 0.00011112 的翻转阈值
  （`cost_coverage_gap_bp = −15.0403`，即距成本覆盖仅差 15.04bp）。

> 以上全部是**参数网格内的条件 P&L 差值**，用于度量决策规则的作用，
> 不是实盘收益、不是策略收益预期、不是胜率预测。

### 3.3 适用边界

- 只在冻结输入快照及其 `data_version` **与 `semantics_version`** 内成立；
  换数据或换口径都必须重跑并对齐 `as_of`。
- `source_mode=degraded`：缺交易所公布 CF、官方交割日历、真实券价与市场融资/借券利率，
  结论为方法复现，不得作为市场结论或交易指令。
- 容量上限由**单账户限仓**约束（200,000 万元面值，5% 参与率 10,000 万元），
  参数同为情景给定；借券存量不参与正向 binding（见 `AUDIT.md` §10 表 C-3）。
- 期货模拟赛只可核验期货腿；现券交割、发票价、借券走等价回放，不冒充成交回执。
- 一阶久期重定价、当前期货价代理交割结算价、网格中点估计切换边界，均为近似。
- **v2 的净结果**：C 的可测价值**全部来自风控跳过规则**（见 §2 归因），
  不来自对冲比率精调；DTW 式的「比率优化带来 alpha」在本快照上不成立。

### 3.4 接入官方数据库后的增量结论（2026-11-14 补充）

用户提示官方数据库凭据在配置中后，实测定位到 `~/.pandadata/pandadata.env`
与 `~/.claude/skills/pandadata-api` 接口契约，登录成功并完成 4 次单次调用。
新增可核验证据：`exchange=CFE` 下 159 个国债期货合约、
`T2612.CFE` 真实交割窗口 2026-12-14~16、锚定日结算价 110.05、交易日历 23 行。

把真实期货价/交割日替换进同一份篮子（现券、CF、成本、容量全部不动）后：

| 指标 | 冻结基线 | 官方锚定 | 作用 |
|---|---|---|---|
| `IRR−r` | 34.74bp | 3019.41bp | +2984.67bp |
| 正向可执行 | False | **True** | 判定翻转 |
| C 跳过情景 | 273/399 (68.42%) | **0/399** | 风控闸门全部打开 |
| C 全网格均值 P&L | 0.019395 | 2.549242 | +2.529847 |

但 live 复跑仍缺关键字段，V 仍不宜按 1.00 估。

## 4. 可靠负结果（同样构成高价值）

1. **正向不可执行**：34.737bp < 49.778bp，账面净基差 −0.0287 不是套利利润。
2. **反向不可执行**：卖空现券/借券能力缺失，参考价差 −94.737bp。
3. **融资变化不改变 CTD**：r 从 0.35% 扫到 4.85%，IRR 与 BNOC 两判据均稳定；
   融资变化只改成本覆盖门槛。这是与「套用价差回归」不同的机制性结论。
4. **静态安全垫不足以保证稳健**：基准点 52.985bp 安全垫，但 +5bp 曲线平移即切换 CTD。
5. **CF 精度是决定性约束**：0.00011112 的 CF 平移即翻转可执行判定 →
   缺官方 CF 时必须缩小范围。
6. **CF 与交割日历缺失本身不加难度**：按题目规则缩小为方法复现，
   不把数据缺口包装成研究深度。
7. **真实期货行情不足以支撑可执行结论**（官方锚定 run）：期货价换成官方结算价后，
   判定翻转、风控跳过率归零，但翻转源于声明式现券与真实行情混用；
   补齐官方可交割券/CF/券价/融资成本前，任何 `forward_executable=true` 都不可采信。
8. **事前口径下 CTD 切换是实打实的持仓风险**：v2 严格事前持有期初 CTD 后，
   399 个情景中 **190 个（47.6%）** 在交割时最优券已不是持仓券，
   事后机会成本均值 **1259.09bp**、最大 **2965.07bp**。
   这不是可以事后追踪的免费收益，而是必须预先定价的风险。
9. **对冲比率精调在本快照上不产生净 alpha**：v2 下 C 相对 B 的全网格均值差
   **+0.086823** 全部来自跳过闸门，对冲比率贡献 ≈ 0（见 §2 归因）。
   「更精细的对冲 = 更高收益」在本快照上**不成立**，这是可靠负结果。
10. **交付物本身可被机器复现，而不是一份需要信任的快照**：
   - 冻结输入快照由 `scripts/build_snapshot.py` **字节级重建**（SHA256 `8cec8a2f…` /
     `d44ca240…` 复核一致）；平台入口写成 `<DSH_HOME>/…` 配方，不随本机盘符变化；
   - 清掉 run 目录、发布快照与页面后，`python scripts/rebuild_all.py` 一次跑通全链路，
     产物数值与原产物**逐点一致**（`strategy_comparison.csv` 除 `update_time` 外哈希相同），
     页面 payload 除 run id 与构建时间戳外**逐段一致**；
   - 修正输入数据（如 `futures_price` 107.32 → 108.60）后 `--refresh-snapshot` 重跑，
     页面上的空间 bp、可执行判定、对照结论措辞与价差**全部自动更新**，
     门禁仍全绿，无需任何手工编辑；
   - 页面模板**不含任何写死的研究结论数值**（静态扫描 + CDP 无头实测双向校验），
     run 定位靠输入事实而非目录名。
   这条决定的是**交付形态的可信度**：审核者不必相信页面上的数字与产物一致，
   可以自己删掉产物再跑一遍。详见 `reports/AUDIT.md` §12。

## 7. 使用与失败边界

复跑命令见 `SKILL.md`。失败即停规则：输入契约不通过退出码 2；
恒等式破坏抛 `AssertionError`；公式对拍 27 条有效断言、单测 **52** 个必须通过；
门禁当前口径：冻结基线 **41** 项、官方锚定 **42** 项（冻结基线含 `cf_flip_explicitly_explained`，
官方锚定 run CF 告警未触发故该项记为 `cf_flip_absence_documented`）

并新增独立复算、双哈希、live 七项门槛、回放声明时序、混合判定无效标记、
**策略 P&L 独立重算、事前持仓断言、终值口径恒等式、语义版本登记**等检查；
比赛 CLI 不可用时只保留等价回放；`degraded` 需显式 `--allow-degraded` 才能发布研究快照。
不适用场景：真实套利判断、实盘盈亏预测、换月/交割滚动、期权调整定价、
时间序列样本外收益评估。
