# 方法论与公式口径

本题核心是**债券现金流 + 可交割券约束 + 融资/借券**，不是价差回归。
全部公式在 `runtime/bonds.py` 实现，恒等式在 `scripts/selftest.py` 与
`tests/test_bonds.py` 用独立推导路径硬断言（27 条有效断言 + 62 个单测，含契约层与产物可重建性防回归）。

独立推导路径为「无票息 IRR」「付息日应计为 0」「半期应计」等；门禁另有一层
「从 run 输入副本独立重算 CTD/IRR 与输出对拍」。`cf_reference_gap` 只反映
舍入误差，不作为校验结论。

## 1. 记号

| 记号 | 含义 | 单位 |
|------|------|------|
| `P_clean` / `AI_0` / `P = P_clean + AI_0` | 结算日净价 / 应计 / 全价 | 每百元面值 |
| `F` / `F_D` | 当前期货报价 / 交割结算价代理 | 每百元面值净价 |
| `CF_i` | 券 i 的转换因子（计算式的输入字段） | 无量纲 |
| `AI_D` | 交割日应计利息 | 每百元面值 |
| `d` / `d_k` | 结算日到交割日 / 第 k 笔票息到交割日的实际天数 | 天 |
| `c_k` | 持有期内第 k 笔票息 = 100×coupon/freq | 每百元面值 |
| `r` | 融资回购利率（单利 ACT/365） | 年化小数 |
| `D_i = P·d/365 − Σ c_k·d_k/365` | 有效融资本金（扣除票息再投资的时间价值） | 每百元·年 |

`CF_i` 的来源必须分清：live 态须为交易所公布值；本交付的两个 run 均为
`degraded`，`CF_i` 由 `reference_cf()` 按 3% 名义标准券折现生成，是参考值而非公布值。

## 2. 应计利息（天数惯例）

```
ACT/ACT (ICMA, 本题默认): AI = c · days(last, settle) / days(last, next)
ACT/365                 : AI = c · days(last, settle) / 365
```
`accrual_period()` 会把付息期滚动到覆盖目标日，因此交割日跨付息期时 `AI_D` 正确。
付息日当天应计为 0（单测硬断言）。**这是本题首要陷阱**：用错天数惯例会整体平移基差。

## 3. 发票价格

```
Invoice_i = F_D · CF_i + AI_D,i
```
中金所实物交割按「期货交割结算价 × 转换因子 + 应计利息」结算。
当前实现用 `F` 代理 `F_D`，属情景假设，已在报告与边界文档标注。
真实交割结算价由交易所按交割月规则产生（并非锚定日结算价），交割窗口
2026-12-14~16 内卖方有择券/择日权；本模型只取最早可交割日单点、不建窗口期权，
因此发票价格不能用于交割损益结算。

## 4. 隐含回购利率 IRR（标准口径）

买入现券 + 卖出期货并持有到交割，令票息按 IRR 自身再投资：

```
P·(1 + i·d/365) = Invoice + Σ c_k·(1 + i·d_k/365)
```

这是 `i` 的**线性方程**，闭式解：

```
IRR = (Invoice + Σ c_k − P) / D
```

`solve_irr_closed()` 同时用二分法独立对拍（误差 > 1e-10 直接抛错）。
另给三个对照口径：
- `irr_at_repo`：票息按市场回购利率 r 再投资；
  `(Invoice + Σ c_k + r·Σ c_k d_k/365 − P) / (P·d/365)`；
- `irr_compound`：复利年化换算 `(1 + IRR·d/365)^(365/d) − 1`；
- 无票息时与「(发票价−全价)/全价 × 365/d」独立推导逐点一致（单测）。

## 5. 净基差 BNOC

```
ForwardProceeds(r) = Invoice + Σ c_k·(1 + r·d_k/365)
GrossBasis         = P_clean − F·CF
NetCarry(r)        = (AI_D − AI_0) + Σ c_k·(1 + r·d_k/365) − P·r·d/365
BNOC_dirty(r)      = P·(1 + r·d/365) − ForwardProceeds(r)   [券价口径]
BNOC(r)            = BNOC_dirty(r) / CF                      [期货报价口径]
```

**三条恒等式**（`evaluate_bond` 内硬断言，输出 CSV 再次校验）：

```
BNOC_dirty(r) = GrossBasis − NetCarry(r)
BNOC_dirty(r) = −(IRR − r)·D
r := IRR  ⇒  BNOC_dirty = 0
```

`BNOC_dirty > 0` 表示「按 r 融资持有到交割的净亏损」；正值不是套利利润。

## 6. CTD 判定与双判据分歧

- 主判据：`argmax IRR`（正向 cash-and-carry 收益率最高）。
- 交叉判据：`argmin BNOC`（净基差最负）。
- 由 `BNOC = −(IRR−r)·D/CF` 可知：**当各券 `D/CF` 相近时两判据一致；
  差异足够大时会分歧**。`rank_basket()` 显式输出 `ctd_disagreement` 与两套排序，不静默取其一。
- 输出 `top2_irr_margin_bp`（前二名 IRR 差）作为 CTD 切换安全垫。

## 7. 情景设计

| 轴 | 网格 | 重定价方式 | 观察量 |
|----|------|-----------|--------|
| 融资利率 r | 基准 r−150bp → r+300bp，步长 25bp（19 点） | 不改券价，改变 r | BNOC、成本覆盖、CTD 判据是否变化 |
| 曲线平移 Δy | −100bp → +100bp，步长 10bp（21 点） | 一阶久期 `P' = P(1 − D_mod Δy)`；`F' = F(1 − D_ctd Δy)` | IRR、CTD 切换边界 |
| 组合网格 | 19 × 21 = 399 情景 | 同上 | 三条策略 P&L、执行/跳过 |

一阶久期重定价是**近似**，不替代真实估值；期货价按 CTD 久期联动，已在报告中标注。
切换边界用网格中点估计，附 `resolution`（本题 10bp），不冒充精确定价解。

## 8. 三条策略的 P&L（每百元面值现券，持有到交割）

### 8.1 事前 / 事后两层必须分清

**事前（结算日可观测）**：期货价 `f0`、给定融资利率 `r`、期初收益率曲线。
据此一次性确定四件事，四者**同源**：

1. 期初 CTD —— 也就是**实际持仓标的** `held_bond`；
2. 期初 IRR `entry_ctd_irr_pct` 与 `entry_irr_minus_repo_bp`；
3. 期初前二名安全垫 `entry_top2_irr_margin_bp`；
4. C 的执行闸门（成本覆盖 + 切换缓冲）。

**事后（仅作风险诊断，不进决策）**：收益率平移 `dy` 之后谁才是最优交割券
（`post_shock_ctd`）、切换造成的事后机会成本（`switch_opportunity_bp`）、
以及「若事先就知道会换券」的 P&L 反事实（`hindsight_C_pnl_per_100`）。

> **v1 的缺陷**：闸门按期初曲线判定，持仓却取冲击后的 CTD —— 事后选券。
> 这不是 C 一条策略的问题：v1 中 A / B / C **三条策略都持冲击后 CTD**，
> 因此前视污染同时污染了冻结基线 A 与 B。v2 一律持有期初 CTD，
> CTD 切换因此成为持仓承担的风险，而非免费收益。

期货腿久期代理 `d_f` 取**期初 CTD 的修正久期**，与持仓标的同源，
且结算日即可知，不含任何事后信息。

### 8.2 终值口径分离（A 与 B/C 的退出方式不同）

```
F_D' = F·(1 − d_f·Δy)                      # 交割结算价代理
Invoice  = F_D'·CF + AI_D                  # 发票价（实物交割口径）
Forward  = Invoice + Σ c_k + r·Σ c_k d_k/365
Market   = 交割日净价(久期一阶重定价) + AI_D + Σ c_k + r·Σ c_k d_k/365

A 买入持有 : Market − P − P·r·d/365 − 摩擦
             （无期货腿、无交割义务 → 只能走现券市场退出）
B 简单对冲 : Forward − P − P·r·d/365 − 摩擦 − 交割费 − h·(F_D' − F),  h = 1
C 研究方案 : 同 B，但 h = DV01 比率，且仅在两条门槛同时满足时执行：
               (a) 期初 IRR − r > 全成本带
               (b) 期初前二名 IRR margin > CTD 切换缓冲
             否则空仓，P&L = 0 并记录 skip_reason
```

**恒等式**（由门禁从输入独立重算对拍，不靠本文档自述）：

```
A − B = valuation_basis_gap + delivery_fee − hedge_leg_pnl_B
        其中 valuation_basis_gap = Market − Forward
```

即 A 与 B 的差额**不是**纯粹的「对冲价值」：必须先扣除估值基准差，
剩余部分才能归因于对冲。`hedge_ratio()` 另提供 `naive_1to1`（冻结基线 B）与
`cf_weighted`（h=CF）。期货腿每手面值 100 万元，折算到每百元面值现券为 1 元/价格点。

## 9. 指标口径（规范 §9.2）

样本区间 = 参数网格；再平衡 = 每情景独立持有到交割、**持仓固定为期初 CTD**
（不随冲击换券）；方向准确率 = P&L(每百元面值) > 0 的情景占比；
最大回撤 = 情景序列累积 P&L 的回撤（**不是资金曲线回撤**）；
换手 = 相邻网格情景上**事后最优交割券**的变化次数（市场侧切换频率代理，
不是持仓换手）；参数网格留出 = `grid_index` 奇偶切分，**不等价于时间序列样本外**；
规则版本 = `data_version` + `semantics_version`（两条独立版本轴）。

新增三块诊断指标：

| 指标 | 含义 | 边界 |
|---|---|---|
| `ctd_switch_exposure` | 持仓券在事后不再是最优交割券的情景占比，以及此时的事后机会成本（bp） | **不可实现**，只作风险度量 |
| `valuation_basis` | A（现券市场退出）与 B/C（实物交割退出）的终值口径差 | 读 `A − B` 前必须先扣除本项 |
| `hindsight_switch_counterfactual` | 若事先知道会换券并改持事后最优券，C 的 P&L 会变化多少 | **不可实现**，且**不是上界**（见下） |

> **事后换券反事实不是上界**：事后最优券按 IRR 选出，而发票价经转换因子缩放，
> IRR 更高的券其 CF 可能更低，绝对 P&L 反而更小，故该差额**可正可负**
> （官方锚定 run 实测下界 −0.067883）。

## 10. 已知陷阱（复现必读）

1. `rolling(n).mean()` 用 cumsum 实现时 `min_periods=1` 分支写错会退化成累计平均；
   本 skill 的金融计算不用滚动窗口，但任何移植必须先逐点对拍。
2. `shift(1)` 不是 `.diff()`；本题 `r := IRR` 的验证用独立调用路径，不做隐式差分。
3. `df.loc[mask,'col']=v` 未匹配行是 NaN 不是 0；本实现用显式 `np`-free 分支与硬断言。
4. 逐行移植 pandas 必须先写单元测试跟独立推导对拍（误差 <1e-9），
   且测试要有硬断言防「两边全 0」假通过。
5. 剔除区间后拼接净值必须按首段末值等比缩放；本题不做区间剔除，避免该坑。
6. **CF 的来源必须显式声明**：交易所公布 CF 含 3% 名义票息、半年复利、
   交割月首日折现、剩余期限取 3 个月整数倍并剔除首期应计等规则，本 skill
   **不反推**该公式。但本交付的 degraded 快照里 `CF_i` 确实由
   `reference_cf()` 生成（年复利、按 `freq` 分期、以交割日下一付息日折现），
   仅为可复算的参考值。此时 `cf_reference_gap` 只是 `round(...,6)` 的舍入误差，
   属自反量，无独立证据价值；只有接入交易所公布 CF 后该差值才有意义。
7. **融资变化 ≠ CTD 切换**：IRR 判据下若票息按 IRR 自身再投资，CTD 与 r 无关；
   r 改变的是成本覆盖与净基差大小。本题融资扫描 0 次切换，是可靠负结果而非缺陷。
8. **交割期权**：空头可在交割时选择最便宜券，净基差因此不为零；
   账面偏差不能直接称为无风险套利。
9. **混合来源判定无效**：官方锚定 run 的 `forward_executable=True` 已由
   `executable_boundary.json` 标记 `verdict_status=INVALID_MIXED_STATE`、
   `conclusion_valid=false`、`forward_executable_usable=false`；
   下游消费必须先读这三个字段，不能只看布尔值。

### 11.1 官方公式与对拍适用范围（证据层，未接入计算）

来源与哈希见 `data/official/cffex_sources.json`；公式原图在
`data/official/cffex_cf_formula.jpg` / `cffex_accrued_formula.png`。

- **转换因子**：`r=0.03`，`c` 为券票息（小数），`f=2`，`x` 为交割月到下一付息月的
  月份数，`n` 为剩余付息次数。折现指数是 **`x*f/12`**，不是 `x/12`；括号内指数是
  `n−1`；末项是 `−(c/f)(1−x*f/12)`；结果四舍五入到 4 位小数。
- **应计利息**：`(票面利率×100 / 每年付息次数) × (第二交割日−上一付息日) /
  当前付息周期实际天数`，ACT/ACT，7 位小数。
- **交割货款**（细则第二十三条）：`交割数量 × (交割结算价 × 转换因子 + 应计利息)
  × (合约面值/100元)`；交割手续费 5 元/手（第二十四条）。
- **对拍结果**：`scripts/cffex_cf.py --verify` 在上市清单 13 只券上 13/13 一致；
  `--verify-all` 对当前全量清单跨 T2612/T2703/T2706 为 43/46，260012/260019 等
  2026 年新发券偏差 0.0005~0.0006 且无法用整数 (x,n) 命中。x/n 计数规则是在
  上市清单子集上反推的，含拟合成分，因此公式复算不作 CF 数据源，
  live 态 CF 原样采用交易所公布值。

**边界**：以上是证据层，两个 run 仍为 `degraded`。
`runtime/pricing.py::reference_cf()` 是声明式参考值；交割细则 PDF 的条款文字
来自网页索引摘录，本地未做 PDF 文本抽取，live 前需人工按页码复核。

## 12. 论文锚定的方法增强（2026-11-18，验证驱动）

本节记录一次「文献 → 可证伪实验 → 只保留正优化」的增量。
原则：任何论文方法必须先用本项目冻结快照独立验证，
证明是正优化且不推翻结论才纳入；负优化如实记录、不落地。
所有产物在 `reports/convexity_enhancement/`，冻结基线、两个 v1 run、哈希、verdict、
当时的 33 项门禁、self-test 27 条断言均未改动（v2 重跑后门禁项数见 `AUDIT.md` §11）。

### 12.1 采纳：二阶凸性重定价（正优化）

**文献**：Fisher & Weil (1971), *Journal of Business* 44(4):410–429，
久期/凸性框架的开创性工作，给出标准二阶展开
`ΔP/P ≈ −D_mod·Δy + ½·C·(Δy)²`。现有 `reprice_bond()` 只用一阶
`P(1−D·Δy)`，本方法论 §11 已自述「±100bp 有线性误差」。

**验证**：`runtime/convexity.py::verify()` 以完整现金流折现为 ground truth
（独立实现路径，并与 `pricing.dirty_price_from_yield` 交叉核对，逐点差 0），
在 21 档 × 4 券上量化：

| 指标 | 一阶（现状） | 二阶（增强） | 变化 |
|------|-------------:|-------------:|------|
| 重定价 RMSE（元/百元） | 0.18898 | 0.00558 | 改善 33.9×（−97.0%） |
| 最大绝对误差（元/百元） | 0.61790 | 0.01820 | 改善 34.0× |
| \|Δy\|≥50bp 的 top2 margin RMSE | 62.26 bp | 2.24 bp | 降到门槛（5bp）以下 |

**结论不变性（关键）**：三种重定价口径（一阶 / 二阶 / 完整折现）下，
CTD 的 IRR 判据与 BNOC 判据逐档排序完全一致，切换边界同为
`0→10bp: C→A`、`20→30bp: A→D`。因此凸性是**纯精度优化**，
不改变任何研究结论。9 项硬断言全通过（见 verification.json）。

**为什么值得做**：一阶的 top2 margin 误差达 62bp，是
`ctd_switch_buffer_bp=5` 的 12 倍——直接威胁策略 C 的 CTD 切换安全垫判定。
凸性把误差压到门槛以下，修复的是风控门槛的可信度，而非美化净值。

**适用性**：Δy² 项在大幅平移才有意义；日常小幅波动一阶已够。
本模块为可选增强层，默认不被 run 链路调用，避免改变冻结产物口径。

### 12.2 未采纳：转换期权（quality option）数值化（负优化，已否决）

**文献**：Kane & Marcus (1986, *JFE*)、Boyle (1989, *JBF*)、
Duffie (1989, *JFQA*) 证明净基差不为零的根源是空头的 CTD 转换/择日期权；
Hemler (1990) 的经验 payoff 法可度量其价值。

**否决理由（可证伪）**：数值化该期权需要收益率波动率与概率分布
（Kane-Marcus 用 1000~10000 条期限结构路径蒙特卡洛）。冻结快照只有
声明式收益率曲线与 21 档确定性平移，**没有任何波动率或概率输入**。
在该输入下若强行估算，波动率只能人为设定——等于编造参数，
违反「缺正式数据不静默填造」的硬约束，属负优化，故不落地数值模块。

**采纳的部分（零风险的语义完善）**：把脚本 §10.8 已有的定性声明具体化——
`top2_irr_margin_bp` 与切换边界是转换期权存在的**可观测代理**
（CTD 会随收益率平移而切换，印证空头择券权的存在），
但**不是期权定价**，不得据此声称测得期权价值。这不新增任何数值。
